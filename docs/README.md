# Documentation

`REP02-D1` dizini WF-02-01 ürün sözleşmesini, alınan kararları, açık kararları ve donanım iddiası sınırlarını kaydeder.

`REP02-D2` dizini WF-02-02 statik rail-budget ile WF-02-03 sequencing sözleşmelerini, sayısal/zamansal politikaları, durum kararlarını, doğrulama sonuçlarını ve sonraki entegrasyon kapılarını kaydeder.

`REP02-D3` dizini WF-02-04 fault-injection sözleşmesini ve WF-02-06'nın ilk raporlama dilimini; recovery, causality, ortak finding görünümü, evidence manifest ve açık entegrasyon kapılarıyla birlikte kaydeder.

D1 sözleşmeleri ve veri modeli, sentetik WF-02-02, WF-02-03 ve WF-02-04 çekirdeklerinin girdilerini sınırlar. D3 yalnız test/kanıt başlangıcıdır; canlı REP-01/03 eşlemesini, fiziksel doğrulamayı veya G1-G6 donanım kapılarını onaylamaz.
