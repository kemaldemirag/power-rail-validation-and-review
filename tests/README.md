# Tests

Bu dizin WF-02-01 sözleşme testlerini ve yalnız sentetik fixture'ları içerir. Testler Python standart kütüphanesindeki `unittest` ile çalışır.

Bir sözleşme testinin `PASS` olması, yalnız makine-okunur veri sözleşmesinin beklenen davranışını doğrular. Fiziksel güç rayı, regülatör kararlılığı veya donanım uygunluğu hakkında kanıt oluşturmaz.
