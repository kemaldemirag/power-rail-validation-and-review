# power-rail-validation-and-review

Durum: SCAFFOLD_ONLY — PRIORITY 2

Amaç; güç bütçesi, derating, sıralama, sentetik hata senaryoları ve kanıt sınıflı inceleme raporları için yeniden kullanılabilir bir araç seti oluşturmaktır.

Bu dizin bir donanım doğrulama motoru değildir. Şu anda kod, model, müşteri şeması veya test sonucu içermez. Gelecekteki her SPICE modeli kaynak, lisans ve model sınırı ile kaydedilecek; transient grafiği tek başına loop stability kanıtı sayılmayacaktır.

Bağımsız Git deposu olarak izlenmektedir; mühendislik içeriği halen iskelet aşamasındadır.
